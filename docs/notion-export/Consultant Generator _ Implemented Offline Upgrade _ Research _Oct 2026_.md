## Implemented
- Exact observed region/delay/universe availability and axis-specific field metrics; normalized partial recorded catalog.
- Isolated, exposure-aware rotating vocabulary; qualified-outcome dataset learning with stale-evidence retraction.
- Same-type semantic AST mutation, compatible crossover, seven vector reducers, recorded GROUP keys and supported argument-role validation.
- Optional third NSGA-II consultant-value objective, explicitly a conservative field-multiplier proxy rather than verified theme attribution.
- Raw check/payload evidence, explicit 2-year Sharpe and realization extraction, unknown evidence kept unknown, and no qualification from missing self-correlation.
- Durable population/decision snapshots, recovery of completed pending offspring without re-simulation, immutable vocabulary/control epochs and effective runtime/operator/settings policy guards.
- Shared uncapped observed trial accounting; interval-aligned return diagnostics correctly named spectral effective rank.
- Advisory-only surrogate ordering, read-only archive review, and offline copy/rescore migration that preserves original DBs.

## Adoption without another pilot
1. Preserve source, databases, checkpoints and bandit files.
2. Compare baseline hashes and run `git apply --check` before applying the patch. Keep unrelated repo files: the ZIP is an overlay.
3. Reproduce the offline verification with the supplied recorded catalog. No credentials are needed.
4. Review existing SQLite archives read-only; migrate only into a new empty directory when the policy differs. Inspect the migration receipt and missing evidence.
No historical campaign SQLite DB was supplied here, so migration/review are fixture-tested interfaces, not a recertification of the handoff's old ready-alpha estimate. The default primary universe favors recorded listing coverage, not an economic/liquidity preference; inspect it before eventual deployment.
## Deliberately not claimed
- Catalog completeness or fresh platform/operator acceptance.
- Verified expression-level pyramid theme attribution.
- Independent-trial counts inferred from AST clusters, true holdout validation, or portfolio-weight-aware Meucci ENB.

- Universal bit-identical recovery through nested refinements, external LLM calls, remote acceptance or missing legacy evidence.
